# CAISSA

CAISSA is a robotic chess board that plays against you without a traditional computer. Instead of running a chess engine in software, the team hardwired a neural network directly into the board's circuitry. You make your move, a matrix of Hall-effect sensors tracks it, and a hidden CoreXY gantry physically slides the response across the board—zero CPU required.

---

## Technologies

- SystemVerilog on an Artix-7 FPGA
- PyTorch (neural network training)
- Hall-effect sensor matrix
- CoreXY gantry
- KiCad PCB design
