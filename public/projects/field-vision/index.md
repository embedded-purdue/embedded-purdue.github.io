# Field Vision

Field Vision is an integrated sideline binocular camera system paired with an in-helmet sensor for athletic concussion detection, combining computer vision on the sideline with impact sensing on the player.

---

## Technologies

- ESP-IDF and SPI
- OpenCV and YOLO
- Computer vision
- KiCad
- C, C++, and Python
