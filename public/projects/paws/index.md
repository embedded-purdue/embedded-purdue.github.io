# PAWS

PAWS is an 8-DOF quadruped robot dog. It runs a reinforcement-learning locomotion policy and computer vision on an ESP32-P4, with firmware written in ESP-IDF and locomotion trained in the MuJoCo simulator before deployment to hardware.

---

## Technologies

- ESP32-P4 and edge AI
- Reinforcement learning (locomotion policy)
- Computer vision and object detection
- MuJoCo physics simulation
- Embedded C / ESP-IDF
- CAN, I2C, and UART peripherals
- CAD and mechanical design
