# BoilerSLAM

BoilerSLAM is a handheld, ergonomic LiDAR SLAM sensor built on a Raspberry Pi 5 and a Livox Mid-360. The system generates real-time 3D maps of GPS-denied environments such as caves, tunnels, and other subterranean spaces, integrating point-cloud and inertial data for accurate localization and mapping.

## Technologies

- Raspberry Pi
- Embedded C/C++
- ROS2
- LiDAR and point-cloud processing
- NX CAD
- Custom PCB
