# IntelliThings

From IoT to AIoT: ESP32-C6 sensor nodes track environmental data and presence, and an LLM agent reasons over the data to control the home through Home Assistant and MCP—with no hand-written automation rules.

---

## Technologies

- ESP32-C6, Rust, and ESP-IDF
- Sensors, MQTT, and addressable LEDs
- Home Assistant, LLM agents, and MCP
- AWS Lambda, chat bot, and dashboard
- PCB design in KiCad; power, Wi-Fi, peripherals, and board bringup
- Python, mechanical/CAD, and 3D printing
